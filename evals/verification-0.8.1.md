# Style coverage verification — 2026-10-17

Scope: Frontend Craft 0.8.1 expands the shared-pattern reference with nine style
families, explicit state/environment coverage, ownership scopes and a targeted
style-update workflow. Mapping, review, ordinary implementation and README routes
point to those contracts. Two evaluation scenarios protect the distinct broad
audit and targeted-update outcomes.

The probes used the new working-tree guidance on top of `fe11fe8`. Later release
metadata and source notes do not change the evaluated workflow. No comparative
baseline, production application or commercial outcome was evaluated.

## Package and authoring checks

- Package validator: metadata shape, portable local links, reference reachability
  and required distribution files.
- Skill Creator metadata validation, using an isolated PyYAML dependency.
- Whitespace checks and an independent read-only authoring review of the matrix,
  update workflow and affected routing. No substantive issue was found in scope,
  reference loading, role preservation or source-versus-rendered evidence rules.
- Isolated Codex and Claude Code project installations, with all installed skill
  files compared byte-for-byte against the source package.

## Workflow probes

Two fresh-context agents used the skill without model or effort overrides. They
received separate copies of a synthetic application and a task, not expected
findings. The fixture consisted of three first-party HTML pages, a shared CSS
file and an adopted-design README. It had operational and marketing families,
light/dark definitions, role-specific headings, forms, navigation, surfaces,
feedback, dialogs, icons, a data table and a reduced-motion rule.

**Application-wide read-only audit:** the agent accounted for all nine families
and reported source ownership, consumers, exceptions and inspection limits. It
identified a field-shape override, a local heading-size bypass, a duplicated
dialog/layer recipe and a table selector overriding numeric alignment. It kept
the marketing family and critical badge as legitimate differences, and explained
that charts/avatars were absent. The root agent compared the audit fixture
byte-for-byte against its initial copy to confirm no modifications or outputs.

**Targeted typography update:** the agent changed the operational title owner to
the requested size, removed its local and dark-theme size overrides, and recorded
the next update location. It preserved the shared primitive token used by card
and marketing headings, left form controls and unrelated audit gaps unchanged,
and kept the change within the requested scope. Source checks covered all three
pages and both theme definitions. The root agent inspected the resulting diff.

## Limits

Both probes supply source evidence only. No browser, computed-style, viewport,
keyboard, forced-color, screen-reader or reduced-motion runtime check ran.
The source audit does not prove every visual condition or interactive state.
The isolated typography update does not establish layout, wrapping or theme
appearance. Plain HTML/CSS fixtures do not prove framework/compiler compatibility
or performance across applications. These are bounded workflow examples, not a
measurement of general agent reliability.

The isolated fixture directories were removed after inspection. Earlier
verification records remain evidence for their named revisions only.
