# Animation opportunity coverage

Date: 2026-10-21. Scope: close the discovery gap identified before releasing
0.10.0. The maintainer's local `find-animation-opportunities` entrypoint declares
no version and has SHA-256
`f2db8db5950ef7ed2ebd0ec73f83534c36742f2aef8b5b9b03d8a953064b027d`.

The [motion guide](../skills/frontend-craft/references/motion.md#find-animation-opportunities)
already owned motion purpose, frequency, static alternatives, implementation,
gestures, interruption, accessibility and inspection. Its new discovery section
adds the following source coverage without another skill dependency:

| Source topic | Bundled treatment |
| --- | --- |
| Reconnaissance | Scope, stack/owners, existing effects/tokens, tone and frequency |
| Feedback gaps | Activation acknowledgment and consequential progress/confirmation without unrequested interaction changes |
| Teleporting state | Conditional content, disclosures, navigation and occasional collection changes |
| Spatial story | Anchored appearance and coherent dismissal paths |
| Group entrances | Contextual sequencing with immediate content/action availability |
| Gesture seams | Continuous drag/release/reorder with cancellation and non-drag access |
| Rare explanatory/success moments | Useful explanation or acknowledgment, preserving truthful state and task completion |
| Frequency/purpose/speed/function gate | Contextual judgment, response cost and evidence rather than universal timing or input bans |
| Search workflow and coverage | Source-located candidates, rendered evidence where available, and inspected/inapplicable/uninspected seam classes |
| Proposal/rejection/verdict report | Prioritized concrete proposals, meaningful rejections, uncertainty and a next action or no-change result |
| Read-only boundary and handoff | No automatic edits; authorized implementation uses existing motion/project owners |

Fixed candidate counts, exact upstream curves, readiness scripts and blanket
rules were deliberately excluded. The source's requirement to keep some motion
in reduced-motion mode yields to the existing accessible static alternatives.
A missing transition in code is a candidate, not proof of a defect.

The [three discovery scenarios](scenarios.md#animation-opportunity-cases) describe
observable acceptance conditions. No fresh-agent opportunity scan or rendered
animation evaluation was performed; static coverage and package validation do not
establish that every proposal will improve a real interface.
